Common Questions

Is this a pirate app?

No. OtakuVerse is a library manager and browser wrapper. We don't host any content; we provide a unified interface for the sites you already visit, helping you track progress safely.

Is it safe?

100%. We are open source on GitHub. You can inspect every line of code. We don't track your data or sell your information.
